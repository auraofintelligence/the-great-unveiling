A multi-page static narrative site in the Aura of Intelligence project family. It presents a
vision, journey, technology themes, initiatives, a library and ways people might explore or join
the wider body of work.

This is public concept framing. It should not be read as proof that every initiative is operating,
funded, approved or technically complete. Claims on individual pages still need to be judged by
their cited evidence and current status.

## Pages

- `index.html` is the public doorway.
- `vision.html` describes the high-level direction.
- `journey.html` presents the journey and travel context.
- `technology.html` introduces the technology themes.
- `initiatives.html` maps connected initiatives.
- `library.html` provides the resource and project-library path.
- `join.html` presents participation ideas.
- `docs/`, `js/`, `styles/` and `assets/` hold the supporting material.

## Use locally

Open `index.html` directly, or serve the folder with `python -m http.server 8000`. The site is
plain HTML, CSS and JavaScript.
